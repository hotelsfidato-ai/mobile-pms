KOT section

What each KOT is, which computer prints it, and where each menu section's dishes go. A computer at the hotel prints through its own printer: the website cannot reach a printer by its address.

This computer

Open this on the computer that has the printer - at the bar, in the kitchen - and tick what it prints.

Set up this computer for printing

On the Windows computer the printer is plugged into, install Fidato Printer. It prints each KOT and bill straight away, with no window and no print screen, starts with Windows and keeps the computer awake. In its window, sign in, open this section, name the computer and tick what it prints. Pick the receipt printer from its icon by the clock: Printer.

Download Fidato Printer for Windows

When it runs, Windows may say "Windows protected your PC": press More info, then Run anyway. The other way, with Chrome: download the setup file - it makes a Chrome shortcut that prints, and your receipt printer the default.
